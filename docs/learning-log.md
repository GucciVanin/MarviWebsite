# Learning log

Gaps the gates missed. Fields: date, item, gap type (missing requirements, unchecked work, lost context at hand-off, unrecorded decision), what would have caught it.

- 2026-10-28 MRV-2.9, gap type: missing requirements (unchecked fact). The spec named a `/client` route that does not exist (the client area is `/portal`). Caught by the Worker and Reviewer. Would have caught it: the Captain grepping app.routes.ts for every path a spec names before issuing the order.
- 2026-10-28 MRV-2.8c/2.9, gap type: unchecked work. A security-relevant escape (`<` replaced with a no-op) and a mailto parameter-injection hole passed the Worker's own tests; only the Reviewer/Security gates found them. Would have caught it: a spec requirement "every sanitizer has a test with a hostile input" in the order template.
- 2026-10-29 MRV-7 (spec), gap type: missing requirements (unchecked fact). The spec numbered the revamp MRV-4.1 to 4.4, ids already taken by older backlog stories (4.1 to 4.10, 5.x, 6.x); only a Worker noticed. Would have caught it: grep `project.md` for the id range before writing the spec (the Captain's spec-intake check).
- 2026-10-29 MRV-7.3/7.4, gap type: unchecked work. Three defects reached the gates only through real-browser checks, not specs or review: fragment links landing under the sticky header (Angular's anchor scrolling ignores CSS scroll-padding), a stuck `anchor-nav` class, and a footer layout shift (CLS 0.9, measured with Lighthouse). jsdom specs cannot see layout. Would have caught it: add a Captain browser/Lighthouse step per slice (done from 7.3 on) and put "measured in a browser" in the Worker's definition of done for any layout or motion AC.
- 2026-10-29 MRV-7.1 to 7.4, gap type: unrecorded decision (overclaiming docs). Four of four Reviewer rounds found `project.md`/`decisions.md` claiming more than was verified (contrast "all pairs", bundle gate arithmetic, spec counts). Would have caught it: the Worker's report template should separate "verified by measurement" from "estimated/inferred", and counts should come from the test run delta, not from counting `it(` blocks.
