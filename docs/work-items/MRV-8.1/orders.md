# MRV-8.1 orders (issue #46) — audit harness and shared layout primitives

Spec: docs/specs/MRV-8.0-layout-box-model.md. This slice serves AC-1, AC-6 (box-sizing rule), AC-7 (tokens), AC-11 (record + command). It does NOT fix page layouts (8.2–8.5); the audit is expected to report violations at the end of this slice, and the baseline is recorded.

- O-1 Build `test/layout/audit.mjs` (+ `test/layout/run.sh`): headless Chromium in Docker (Playwright image, version pinned), targets the dev stack at http://host.docker.internal:4200. Signs in via the real API/UI with the seeded demo accounts (admin password read from deploy/.env, never printed or committed), visits every public and portal route at 320, 375, 414, 768, 1024, 1280, 1440, 1920. Implements checks AC-2 (overflow), AC-3 (overlap), AC-4 (wrapped single-line controls), AC-5 (alignment of form fields/rows/cards), AC-6 (box exceeds parent, box-sizing). Output: one line per violation (route, width, selector, rule) plus a JSON summary; non-zero exit on any violation. Deterministic: wait for network idle and fonts, disable animations/transitions, fixed viewport and DPR.
- O-2 Self-test: a small fixture page set (`test/layout/fixtures/`) with one deliberate violation per rule; the audit must flag each and pass a clean fixture, proving the checks work.
- O-3 Shared primitives in `client/src/styles` (tokens/base only, no page rewrites): global `*, *::before, *::after { box-sizing: border-box }` if missing, spacing scale and container-width tokens, utility/layout mixins (`.stack`, `.cluster`, `.grid-auto` with gap and `min-width: 0`) that later slices use. No visible change to existing pages.
- O-4 Record the baseline run (violation counts per route/width/rule) in `docs/tests/layout-audit.md` with the run command and environment; add the audit to docs/tests index. Update project.md/architecture.md as the Definition of Done requires.

Constraints: do not edit page templates or component styles beyond the primitives; no API changes; no credentials in files or logs; dev DB untouched (the audit only reads and signs in); no new runtime dependency in the client bundle (tooling lives under test/layout only).
