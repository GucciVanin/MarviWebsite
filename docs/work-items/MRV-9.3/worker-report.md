3. **Race on create**: every create/update/delete runs in one transaction that first runs `SELECT 1 FROM client_accounts WHERE id = @id FOR UPDATE` and only then reads the addresses, so parallel requests on one customer take turns. 5. **Audit of a deleted address** names the customer: every address audit entry carries `CustomerNumber` in its details and `AdminAuditLogController` uses it when the row is gone (`TheAuditEntry_OfARemovedAddress_StillNamesTheCustomer`; runtime check on Postgres).
